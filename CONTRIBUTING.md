# Contributing

Thanks for your interest in this collection.

**Suggesting a skill:** open an issue describing the workflow you want and any example inputs/outputs.

**Submitting a skill:** fork the repo, add your skill folder following the existing structure (SKILL.md + supporting steering files), then open a pull request describing what it does and who it's for.

Keep skills scoped to one clear job, document usage with a real example prompt, and note any limitations honestly.
